# Base Power & AITX Talent Hackathon: the official rules we build against

Source: the official Notion page, https://common-scooter-829.notion.site/Base-AITX-Talent-Hackathon-3e01e636288e80a7b914c993f90ae6c5 (read Sep 25, 2026). Luma: https://luma.com/aitx-94j6.

- **Where and when:** Base Power HQ, 205 E. Riverside Dr, Suite 100, Austin, TX 78704 · Sep 25–27, 2026 · in person. Base engineers judge, and Base is hiring in Texas off what gets built.
- **Tracks.** Pick one of three; **one project may enter up to 2**:
  - **Open Grid Data:** "ERCOT publishes more public grid data than almost any market on earth: prices, load, generation, congestion… Show us what you can see in the data that most people miss."
  - **Orchestration:** "Build a system that coordinates many independent things… What matters is how it holds up when pieces fail."
  - **Most Commercializable:** "Base is a power company, not a battery company, and is building a world-class product for its members… Show off your taste."
- **Judging (100 points), done off the 5-minute demo video and the codebase.** "Real, working systems — not slide decks or simple API wrappers."
  - Technical Execution & Completeness 30: completeness 15, technical depth 15.
  - Fit to the Track 30: the problem 15, the "why" 15.
  - Value & Impact 20: insight quality 10, usability 10.
  - Innovation and Execution 20: creativity/look and feel 10, performance (speed or scale) 10.
- **Submission:** due **Sunday Sep 27, 11:00 AM CT** on Airtable (https://airtable.com/appWQWPtBqDUhCPPj/shrU4GuBeUnMzyrd5). One submission per team.
  - Project title.
  - **2–5 min Loom demo video**, camera on, core loop shown live. Recommended flow: team intro ≤30 s, pitch ≤30 s, live demo, how it's built, "so what".
  - **Public repo** whose README has: quick start; tech stack and architecture diagram; how to reproduce the demo (env vars, API keys, sample .env); datasets and provenance; known limitations and next steps.
  - Deployed URL or screen capture; team roster; 150–300 word write-up.
- **Schedule highlights:**
  - Fri: kickoff 5:30 PM, build 7 PM–12 AM.
  - Sat: doors 8 AM, **Base Office Hours 11 AM–1 PM**, factory tours 10:30 AM and 1:30 PM (closed-toe shoes).
  - Sun: submissions 11 AM, judging 11 AM–2 PM, awards 2–3 PM.
- **Not stated on the page:** prizes, provided data or APIs, team size, or any rule about code written before the event (see "What existed before the event" in the README).
